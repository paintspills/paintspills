    Help & About

    What it does

    Barcode-O-Matic makes Code 39 barcode labels for inventory, equipment and supplies, and plain text labels too. It prints on thermal label rolls (one label at a time) or on Avery 5160 sheets (30 per page).

    Text-only labels

    • On the Labels tab, set Label type to Text only. Each line in the list is one label.
    • Use | to put more than one line on a label: Scissors | Cabinet 3.
    • Text sizes itself to fill the label. The Design tab sets font, alignment, bold, largest size, wrapping and an optional border.
    • Barcode and text lists are kept separately, so switching type doesn't lose either one.

    Quick start

    1. Labels tab: type or paste codes, one per line (CODE | Title adds a title), or make a numbered Sequence or Import a CSV file.
    2. Printer tab: choose your label stock and run Print alignment test once per printer.
    3. Click Print labels, then scan a few with the Verify tab to confirm they read.

    Code 39 basics

    • Allowed: 0-9 A-Z - . $ / + % and space. Lowercase letters become uppercase.
    • Shorter codes print bigger, easier-to-scan bars. The Design tab shows the longest code that fits your label.
    • The * start/stop marks are added automatically and are never sent by the scanner.
    • No check digit is used, so any scanner with Code 39 turned on reads these labels. Code 39 is on by default on most scanners.

    Printing on sheets

    • Paper US Letter, Scale 100% / Actual size, Margins None, headers & footers off.
    • Print the alignment test on plain paper, hold it over a label sheet against a light, and use the nudge sliders if needed.
    • Partly used sheet? Mark the used slots so they're skipped.

    Printing on thermal rolls

    • In your printer's Printing Preferences, create a paper/stock size that matches your labels (for example 50 × 25 mm for 2″ × 1″) with margins of 0.
    • Leave Paper size comes from on Printer driver. In the print dialog pick that paper size, Margins None, Scale 100%, and the Layout that makes the preview look like your label.
    • The alignment test prints a mm ruler. On each side, the smallest number you can still see is how many mm are being cut off.
    • If one label prints as a narrow strip across two labels, the job went landscape. Change Layout, or switch Paper size comes from to the other option.

    Your data

    • Everything stays in this browser on this computer. Nothing is uploaded.
    • A different browser, computer or web address starts with fresh settings.
    • Clearing browser data erases your list, settings and print history. Use Export list as CSV and the History tab's Export CSV to keep copies.
