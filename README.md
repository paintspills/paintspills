# PaintSpills

PaintSpills is a collection of simple, browser-based creative tools for art, animation, and classroom projects. The site is designed to run as a static web project, making it easy to host with GitHub Pages, Cloudflare Pages, Netlify, or another static hosting service.

## Project Goals

PaintSpills is meant to be:

- Easy to use on Chromebooks
- Free from unnecessary logins or ads
- Useful for classroom art and animation workflows
- Simple to host as a static website
- Built with HTML, CSS, and JavaScript
